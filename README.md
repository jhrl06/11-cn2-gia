## 优惠码到手之后怎么用

下单流程本身简单，但有一个环节最容易漏：

1. 选好套餐，点 Order Now 加入购物车；
2. 选付款周期和机房；
3. 在结算页 Promotional Code 输入框填入优惠码；
4. **点 Validate Code**，确认价格变成折后价；
5. 付款。

第 4 步跳过的话码等于没填，付的就是原价。还有三条规则要记住：新码只对**新下单的机器**生效，账户里已有的机器续费用不了；优惠码不能事后补，原价买完找客服要折扣行不通；循环折扣按付款周期生效，所以年付一次锁一整年，比月付划算。往年大促码标注「全场通用」，今年 5 月新上的新加坡 SG_8 机房（$49.99/月起）大概率也在范围内，最终以结算页显示为准。
